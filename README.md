# Task List (Android)

A simple Android app to add, complete and delete daily tasks. Tasks are saved on the device, so they are still there after you close the app.

## Built with
- Kotlin
- RecyclerView with ListAdapter and DiffUtil
- Material Design components
- SharedPreferences (JSON) for local storage

## Features
- Add a task with the button or the keyboard's Done key
- Tick a task to mark it done (shown with a line through it)
- Delete a task
- Live count of finished tasks

## How to run
1. Install Android Studio.
2. Choose **Open** and select this folder.
3. Wait for Gradle sync to finish.
4. Press **Run** with an emulator or a connected phone.

Minimum Android version: 7.0 (API 24).
